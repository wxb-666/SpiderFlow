# SpiderFlow 需求说明书

## 1. 项目背景与目标

### 1.1 项目背景

外汇牌价会随市场变化持续更新，手工查看、记录和比较不同日期的汇率数据效率较低，也不利于后续进行趋势分析。本项目拟开发一个轻量级的外汇牌价采集与分析系统，定时采集公开可访问的外汇牌价数据，统一保存到 MySQL，并生成基础的历史波动分析结果。

项目以完整实践 Python 爬虫、自动化调度、数据处理、数据库操作和 Docker 部署为主要目标，适合作为两天内可交付的学习型项目。

### 1.2 项目目标

- 使用 Scrapy 从已确认允许访问的公开外汇牌价页面采集汇率数据。
- 每日自动执行采集、清洗、入库和分析流程，并记录任务执行结果。
- 使用 Pandas 对历史汇率计算涨跌幅、近 7 日均值和区间最高/最低值。
- 使用 MySQL 持久化币种、汇率快照和任务运行日志，提供基础增删改查能力。
- 使用 Docker Compose 一键启动应用服务与 MySQL，避免依赖本机 Python 或数据库环境。

## 2. 项目边界

### 2.1 项目范围

- 采集公开页面中展示的币种名称、现汇买入价、现汇卖出价、现钞买入价、现钞卖出价、中行折算价及发布时间等字段。
- 首期关注美元、欧元、日元、英镑等常用币种；系统保留扩展全部页面币种的能力。
- 每日生成一份汇率快照并写入 MySQL。
- 提供命令行查询能力，可查询指定币种在指定日期范围内的历史数据。
- 生成 CSV 格式的汇率分析结果，供查看或二次处理。
- 通过容器内定时任务在工作日设定时刻自动运行。

### 2.2 非项目范围

- 不提供外汇交易、换汇、投资建议或预测功能。
- 不绕过验证码、登录限制、反爬机制或网站访问限制。
- 不开发 Web 前端、移动端页面和用户账户体系。
- 不保证数据源实时性；数据以源站公开页面在采集时刻展示的内容为准。
- 不进行高频抓取，不采集需要登录、付费或未获授权的数据。

## 3. 核心功能需求

### 3.1 汇率数据采集

- 使用 Scrapy 编写爬虫，从配置的数据源页面抓取外汇牌价表格。
- 对字段进行清洗和标准化：去除空白字符、将价格转换为数值、统一发布时间格式。
- 设置合理的下载延迟、请求头和失败重试次数，遵守数据源 robots 规则及使用条款。
- 采集失败时记录错误信息，避免写入不完整或格式异常的数据。

### 3.2 数据库存储与管理

- 维护币种信息表，保存币种编码、名称和启用状态。
- 维护汇率快照表，按“币种 + 发布时间”保存每日汇率数据，并防止重复写入。
- 维护任务运行日志表，记录任务名称、开始时间、结束时间、执行状态、采集数量和错误摘要。
- 提供基础 CRUD 脚本：新增币种、查询历史汇率、更新币种启用状态、删除指定日期范围的测试数据。

### 3.3 数据分析与结果输出

- 使用 Pandas 从 MySQL 读取历史汇率数据。
- 按币种计算中行折算价的日涨跌额与日涨跌幅。
- 计算近 7 个有效数据日的移动平均值。
- 统计查询周期内的最高价、最低价及其对应日期。
- 将明细和汇总结果分别导出为 CSV 文件；当历史数据不足时，输出可理解的空结果或提示信息。

### 3.4 定时任务与可观测性

- 使用 APScheduler 或 cron 在工作日固定时刻触发主任务。
- 主任务按“采集 -> 校验 -> 入库 -> 分析 -> 记录日志”的顺序执行。
- 单次任务失败不影响下一次定时触发。
- 支持手动运行同一任务，便于首次初始化和排查问题。
- 容器日志应输出关键阶段、采集数量和异常信息。

### 3.5 Docker 部署

- 使用 Docker Compose 编排 MySQL、爬虫/分析服务和调度服务。
- MySQL 数据目录使用命名卷持久化，重启容器后保留数据。
- 通过环境变量配置数据库连接、定时表达式和数据源地址，不在代码中写入敏感配置。
- 提供初始化 SQL、示例环境变量文件和部署说明。

## 4. 技术栈总览

| 分类 | 技术选型 | 用途 |
| --- | --- | --- |
| 编程语言 | Python 3.11 | 爬虫、任务调度、数据分析和数据库操作 |
| 爬虫框架 | Scrapy | 请求调度、页面解析、异常重试和数据管道 |
| 数据处理 | Pandas | 汇率清洗、指标计算、CSV 导出 |
| 数据库 | MySQL 8.0 | 存储币种、汇率快照和任务日志 |
| 数据库访问 | SQLAlchemy 或 PyMySQL | 建表及数据增删改查 |
| 自动化调度 | APScheduler | 每日定时执行采集与分析任务 |
| 容器化 | Docker、Docker Compose | 统一运行环境和服务编排 |
| 配置管理 | python-dotenv、环境变量 | 管理数据库连接和运行参数 |

### 验收标准

- `docker compose up -d` 后，MySQL 与应用服务均可正常启动。
- 手动触发任务后，能够采集、校验并保存至少一组有效汇率数据。
- MySQL 中能够查询到汇率快照和对应任务运行日志。
- 分析任务能够基于库中数据生成 CSV 结果。
- 定时任务配置生效，且任务失败信息可从日志中定位。
